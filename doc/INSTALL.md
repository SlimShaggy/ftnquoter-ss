# Установка и тестирование ftnQuoter v2.0

### Вариант 1: Временная установка для тестирования (рекомендуется для разработки)

1. Откройте Thunderbird
2. Откройте меню **☰ → Дополнительные инструменты → Консоль отладки дополнений**
3. Нажмите кнопку **Загрузить временное дополнение...**
4. Выберите файл `manifest.json` из **корневой директории проекта** (не из `src/`)
5. Расширение будет загружено и активно до перезапуска Thunderbird

**Примечание:** При временной установке расширение нужно будет перезагружать после каждого перезапуска Thunderbird.

### Вариант 2: Установка из XPI (постоянная установка)

#### Шаг 1: Сборка XPI

```bash
# Находясь в корневой директории проекта
npm install
npm run build
```

Будет создан файл `ftnquoter-2.0.0.xpi` в корневой директории проекта.

**Что происходит при сборке:**
- Скрипт `build.js` создаёт ZIP-архив
- Включаются: manifest.json, src/, icons/
- Исключаются: node_modules/, doc/, build.js, package.json, иконки SVG

#### Шаг 2: Установка в Thunderbird

1. Откройте Thunderbird
2. Откройте меню **☰ → Дополнения и темы** (или нажмите `Ctrl+Shift+A`)
3. Нажмите на **шестеренку** (⚙️) в правом верхнем углу
4. Выберите **Установить дополнение из файла...**
5. Выберите файл `ftnquoter-2.0.0.xpi`
6. Подтвердите установку

## Настройка

1. После установки откройте **☰ → Дополнения и темы**
2. Найдите **ftnQuoter** в списке
3. Нажмите на расширение и выберите **Настройки**
4. Настройте параметры по своему вкусу

```

Цитировать пустые строки: ☐
Цитировать подпись: ☐
Использовать цветовую разметку: ✓
Цвет первого уровня: blue
Цвет второго уровня: brown
Добавлять заголовок X-Comment-To: ✓
Использовать flowed формат: ☐
```

## Тестирование

### Тест 1: Базовое цитирование

1. Создайте тестовое письмо с темой "Test Message"
2. Отправьте его себе или на тестовый адрес
3. Откройте письмо и нажмите **Ответить**
4. Проверьте, что текст процитирован в FTN-стиле с инициалами

**Ожидаемый результат:**
```
 AB> Исходный текст сообщения
 AB> будет процитирован с инициалами
```

### Тест 2: Многоуровневое цитирование

1. Ответьте на письмо, которое уже содержит цитирование
2. Проверьте, что уровни цитирования увеличиваются

**Ожидаемый результат:**
```
 CD> AB> Текст первого уровня
 CD> AB> цитирования
 CD> Текст второго уровня
```

### Тест 3: X-Comment-To заголовок

1. Ответьте на письмо от "John Doe <john@example.com>"
2. Перед отправкой откройте **Просмотр → Заголовки → Все**
3. Проверьте наличие заголовка `X-Comment-To: John Doe`

### Тест 4: Фильтрация по группам

1. Убедитесь, что в настройках указан шаблон: `^(fido7\.|.*<.*@.*>).*$`
2. Ответьте на письмо с адресом `user@example.com` — должно сработать
3. Ответьте на письмо с адресом в группе `fido7.ru.linux` — должно сработать
4. Ответьте на письмо не подходящее под шаблон — цитирование НЕ должно применяться

## Отладка

### Просмотр логов

1. Откройте **☰ → Дополнительные инструменты → Консоль браузера** (`Ctrl+Shift+J`)
2. В фильтре введите `ftnQuoter`
3. Вы увидите сообщения типа:
   ```
   ftnQuoter: initialized
   ftnQuoter: settings loaded: {...}
   ftnQuoter: extracted initials: SP from "Sergey Poziturin <sp@example.com>"
   ftnQuoter: applied FTN-style quoting
   ```

### Частые проблемы

#### Цитирование не применяется

**Возможные причины:**
1. Расширение отключено в настройках
2. Получатель не соответствует шаблону групп
3. Письмо не является ответом (Reply)

**Решение:**
- Проверьте настройки
- Проверьте логи в консоли браузера
- Убедитесь, что шаблон групп корректен

#### Цвета не отображаются

**Причина:** По умолчанию Thunderbird может игнорировать цвета в сообщениях.

**Решение:**
1. Откройте настройки Thunderbird
2. Перейдите в **Общие → Язык и внешний вид**
3. Нажмите **Цвета...**
4. Убедитесь, что включена опция **Использовать системные цвета**

#### Иконки не отображаются

**Решение:**
1. Откройте `modern-extension/icons/create-icons.html` в браузере
2. Скачайте сгенерированные PNG файлы
3. Сохраните их как `icon-48.png` и `icon-96.png` в директории `icons/`
4. Пересоберите расширение

## Сборка и распространение

### Создание релиза

```bash
# 1. Убедитесь, что все файлы на месте
ls -R

# 2. Установите зависимости (если ещё не установлены)
npm install

# 3. Соберите XPI
npm run build

# 4. Проверьте содержимое
unzip -l ftnquoter-2.0.0.xpi
```

**Ожидаемое содержимое XPI:**
```
Archive:  ftnquoter-2.0.0.xpi
  manifest.json
  src/background.js
  src/display-script.js
  src/compose-script.js
  src/options/options.html
  src/options/options.css
  src/options/options.js
  icons/icon-48.png
  icons/icon-96.png
```

### Публикация на addons.thunderbird.net

1. Зарегистрируйтесь на https://addons.thunderbird.net
2. Создайте новое дополнение
3. Загрузите файл `ftnquoter-2.0.0.xpi`
4. Заполните описание и метаданные
5. Дождитесь проверки модераторами

## Дополнительные команды npm

```bash

npm run lint

# Запуск в режиме разработки с автоматическим открытием TB и консоли
```

**Примечание:** Команды `lint` и `watch` используют пакет `web-ext`, который должен быть установлен через `npm install`.
