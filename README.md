# ftnQuoter v2.0 - Modern Edition

FTN-style message quoter for modern Thunderbird (115+)

## ⚠️ Предупреждение:

**Современный Thunderbird (115+) использует кодировку UTF-8 для всех сообщений.** Это создаёт проблемы при работе с русскоязычными эхоконференциями FidoNet, которые традиционно используют CP866. Ваши сообщения с кириллицей могут отображаться кракозябрами у участников, использующих классические редакторы (GoldED и т.д.). Требуется перекодировка на сервере или гейте.

**Данное расширение не может обойти это ограничение Thunderbird!** Используйте его только если понимаете последствия или работаете с UTF-8-совместимыми эхами.

---

## Описание

ftnQuoter — это расширение для Mozilla Thunderbird, которое применяет стиль цитирования сообщений, используемый в FidoNet (FTN). Вместо стандартных символов `>` оно использует инициалы автора, например `AB>`, что делает цитирование более наглядным и традиционным для FidoNet-сообществ.

## История

Это современная версия оригинального расширения ftnQuoter v0.9, созданного Sergey Poziturin в 2010 году. Код был полностью переписан для совместимости с Thunderbird 115+ с использованием современных WebExtension API.

## Возможности

- ✅ **FTN-стиль цитирования** — автоматическая замена стандартного `>` на инициалы автора (например, `SP>`)
- ✅ **Форматирование строк** — автоматическое разбиение длинных строк (по умолчанию 72 символа)
- ✅ **Цветовая подсветка цитат** — разные цвета для разных уровней цитирования при просмотре и композиции
- ✅ **Вложенные цитаты** — корректная обработка многоуровневых цитат (`VP>` → `VP>>`)
- ✅ **X-Comment-To заголовок** — автоматическое добавление заголовка с именем адресата (для FidoNet)
- ✅ **Фильтрация по группам** — применяется только к сообщениям, соответствующим регулярному выражению
- ✅ **Настраиваемые параметры** — полная настройка через удобный интерфейс

## Использование

1. После установки расширение работает автоматически
2. При ответе на письмо, если получатель соответствует заданному шаблону, будет применено FTN-цитирование
3. Настройте параметры через **Меню → Дополнения и темы → ftnQuoter → Настройки**

## Настройки

### Основные настройки

- **Включить ftnQuoter** — глобальное включение/выключение расширения
- **Максимальная длина строки** — количество символов в строке (по умолчанию 72)
- **Шаблон групп** — регулярное выражение для фильтрации сообщений (например, `^(fido7\.|.*<.*@.*>).*$`)

### Опции цитирования

- **Цитировать пустые строки** — добавлять символы цитирования к пустым строкам
- **Цитировать подпись** — включать подпись (строки после `--`) в цитирование
- **Использовать flowed формат** — применять format=flowed для простых текстовых сообщений

### Настройки цвета

- **Использовать цветовую разметку** — применять цвета к разным уровням цитирования
- **Цвет первого уровня** — цвет для цитат первого уровня (например, `blue`)
- **Цвет второго уровня** — цвет для цитат второго уровня (например, `brown`)

### Опции FidoNet

- **Добавлять заголовок X-Comment-To** — автоматически добавлять имя адресата в заголовок

## Пример

### До (стандартное цитирование Thunderbird):

```
> This is a quoted message
> from another person
```

### После (FTN-стиль):

```
 SP> This is a quoted message
 SP> from another person
```
